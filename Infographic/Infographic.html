User authentication and session management
Auth
🔐 Supabase Auth
Handles user registration, login, and secure session management using JWTs. Supports email/password and OAuth providers. Row-level security (RLS) in the database ensures each user can only access their own job data, resumes, and applications.
JWT tokens OAuth support Row-level security
User Dashboard
Applications · Resume · Status tracking views
Dashboard
📊 User Dashboard
The command center for the user. Displays matched jobs, application statuses (applied, viewed, rejected, interview), resume versions, and pipeline health. Users can pause automation, manually review jobs, and download tailored resumes from here.
Live status feed Resume manager Analytics view
⚙️ Backend / AI Agent Layer
The brain of the platform. A FastAPI service orchestrates a chain of specialized AI agents — scraping jobs, filtering by profile match, optimizing resumes, auto-applying, and tracking outcomes. Each agent is independently scalable and communicates via internal queues.
FastAPI Python agents Google Gemini AI Redis task queue
Backend (apps/agent)
2
FastAPI App
REST API gateway — routes all frontend requests
🚀 FastAPI App
The API gateway between the frontend and the agent pipeline. Exposes endpoints for triggering job scans, fetching matched results, retrieving optimized resumes, and querying application status. Uses async/await for high-throughput non-blocking I/O. Auto-generates OpenAPI docs.
Async Python OpenAPI / Swagger Pydantic validation
3
Collector Orchestrator
Coordinates all agent pipelines and job discovery workflows
Orchestration
🎛️ Collector Orchestrator
The master controller that sequences the entire agent pipeline. It triggers scrapers in parallel, waits for results, fans them into the AI filter, then routes matched jobs to the resume and apply agents. Manages retries, timeouts, and failure recovery across all sub-agents.
Pipeline coordination Parallel execution Retry logic
4
Job Scrapers
Naukri · LinkedIn · JobSpy — multi-platform data collection
Data Collection
🕷️ Job Scrapers
Three platform-specific scraper modules that collect job postings in parallel. Each scraper handles login simulation, pagination, and anti-bot evasion strategies. Collected data (title, JD, salary, location, skills) is normalized into a unified schema before passing downstream.
Naukri scraper LinkedIn scraper JobSpy API Data normalization
5
AI Job Filter Agent
Matches scraped jobs against user profile using Gemini AI
AI · Filtering
🤖 AI Job Filter Agent
Uses Google Gemini to semantically match scraped job listings against the user's profile, skills, experience level, and preferences. Scores each job 0–100 and filters out low-relevance listings. Handles nuanced matching like "5 years React" vs "senior frontend engineer".
Google Gemini LLM Semantic scoring Profile matching
6
Resume Optimization Agent
Customizes resume content for each job description via AI
AI · NLP
📝 Resume Optimization Agent
For each matched job, this agent rewrites the user's base resume — adjusting the summary, reordering skills, and highlighting relevant experience — to maximize ATS score and recruiter relevance. Each version is stored and linked to its specific job application in the database.
Gemini text gen ATS optimization Per-JD versioning
7
Job Apply Agent
Automated form filling and submission on job platforms
Automation
📤 Job Apply Agent
Automates the actual application process using browser automation. Navigates to the job page, fills in fields (name, email, experience, cover letter), attaches the optimized resume, and submits the form. Handles CAPTCHAs, multi-step forms, and platform-specific quirks gracefully.
Browser automation Form intelligence CAPTCHA handling
8
Application Tracking Agent
Monitors and updates application status across all platforms
Monitoring
📡 Application Tracking Agent
Periodically checks the status of submitted applications by revisiting platform dashboards or parsing email notifications. Updates the database with status changes (viewed, shortlisted, rejected, interview scheduled) and pushes real-time notifications to the user dashboard.
Scheduled polling Email parsing Status webhooks
🗄️ Data & External Services
The persistence and intelligence backbone. PostgreSQL stores all user data, jobs, and applications with row-level security. Redis manages async job queues and caching. Google Gemini provides the AI reasoning, while external job platforms are both data sources and application targets.
PostgreSQL Supabase Redis Gemini API
Data & External Services
PostgreSQL / Supabase
Primary database — users, jobs, applications, resumes
Primary DB
🐘 PostgreSQL / Supabase
The primary relational database storing all platform data: user profiles, scraped job listings, application records, versioned resumes, and agent logs. Supabase wraps Postgres with a RESTful API, real-time subscriptions, and built-in row-level security policies per user.
Row-level security Real-time subscriptions Auto REST API
Redis Cache / Queue
Job queues, session cache, async task management
Cache · Queue
⚡ Redis Cache / Queue
Dual-purpose in-memory store. As a cache: stores scraped job results and Gemini API responses to avoid redundant calls. As a queue (via Redis Streams or RQ): manages the async agent task pipeline so scrapers, filters, and apply agents process jobs independently without blocking each other.
Task queuing Response caching Rate limit buffer
Google Gemini AI
LLM for job filtering and resume optimization
External AI
✨ Google Gemini AI
The large language model powering both the AI Filter Agent and the Resume Optimization Agent. Called via the Gemini API with structured prompts. Handles semantic job-profile matching, relevance scoring, and natural language resume rewriting. Results are cached in Redis to minimize API costs.
Gemini 1.5 Pro Structured prompts Cached responses

External APIs
🌐 Job Platforms
External job boards that serve a dual role: they are the data sources for scraping listings AND the submission targets for the apply agent.
